Política de privacidade do Mapa do Braço

Última atualização: 11 de novembro de 2026

O Mapa do Braço é um aplicativo para estudar guitarra. Ele foi feito para funcionar inteiramente no seu aparelho.

Dados que o app guarda

Seu progresso (aulas concluídas, recordes de andamento, repertório, preferências) fica salvo apenas na memória do seu aparelho. O app não tem cadastro, não pede nome, e-mail nem telefone e não envia esses dados para nenhum servidor.

Microfone

O app pede acesso ao microfone para o afinador, para praticar licks tocando junto e para o gravador. O som é analisado no próprio aparelho, na hora, e não é enviado para lugar nenhum. As gravações só ficam no aparelho e só são salvas se você mesmo escolher salvar.

Arquivos de áudio

Quando você escolhe uma música para o app identificar os acordes, o arquivo é lido e analisado no aparelho. O áudio não é enviado nem guardado; apenas o resultado (tom, andamento e acordes) fica salvo no seu repertório.

Internet

O app pode usar a internet só para carregar as fontes de letra do visual. Não há anúncios, rastreadores ou ferramentas de análise de uso.

Apagar seus dados

Em Progresso, use “Apagar meu progresso”. Desinstalar o app também apaga tudo o que ele guardou.

Crianças

O app não coleta dados de ninguém, incluindo crianças.

Contato

Dúvidas sobre esta política: abra uma issue no repositório do projeto no GitHub (josuenino33/guitarra-do-zero-ao-pro).
